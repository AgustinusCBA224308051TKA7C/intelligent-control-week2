Pada praktikum ini, dilakukan percobaan untuk mengklasifikasikan objek menggunakan Scikit-learn dengan menerapkan dua metode algoritma, yaitu K-Nearest Neighbors (KNN) dan Support Vector Machine (SVM). Langkah pertama yang dilakukan adalah meng-clone repositori dari GitHub ke Visual Studio Code. Selanjutnya, dilakukan instalasi library yang dibutuhkan. Setelah itu, dibuat dataset warna yang akan digunakan dalam proses deteksi warna. Tahap berikutnya adalah membuat program deteksi untuk masing-masing metode, baik untuk KNN maupun SVM, dengan menghubungkannya ke dataset yang telah dibuat sebelumnya. Setelah semua kode siap, dilakukan proses running untuk masing-masing metode deteksi. Pada metode KNN, hasil deteksi meliputi label warna, bounding box, nilai akurasi, dan Confidence Score. Sementara itu, pada metode SVM, output yang diperoleh meliputi dua titik deteksi, bounding box, label warna, Confidence Score, dan nilai akurasi.
